# LaTeX Links

## Installation
[LaTeX Project](https://www.latex-project.org)

### Windows
Windows users might find [MiKTeX](https://miktex.org/download) the easiest to work with. 

### Mac
While you can install a singular LaTeX package, I'd suggest first installing [Homebrew](https://brew.sh) and then using that to install MacTex.  While you're at it, install `aspell` too.  Once you have these installed, you should be able to replicate all LaTeX in the course GitHub.

### GNU Linux
Okay, so the exact variant of GNU Linux you're using matters here, but generally, install both `texlive` and `pdflatex`. While you're at it, install `aspell` too.  Once you have these installed, you should be able to replicate all LaTeX in the course GitHub.
