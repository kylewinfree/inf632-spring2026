In this directory, you will find LaTeX source materials for all class lectures and assessments.

To make building pdfs quick and easy, as well as to ensure that everything is spell checked along the way, latex_course_documents.sh enters each specified directory to run pdflatex and then moves the generated pdf to the repo root.

You will need texlive or MacTex to build the pdfs from the LaTeX source.  You will also need bash to call the .sh (execute with $ bash latex_course_documents.sh).
